# Why Do We Need a Spacing System?

Imagine you're building a house.

Would a mason measure like this?

```
7 cm
13 cm
19 cm
22 cm
31 cm
```

❌ No.

Instead, they use standard measurements like:

```
10 cm
20 cm
30 cm
40 cm
```

Why?

Because standard measurements are:

- Easier to follow
- Consistent
- Faster to work with
- Professional

UI designers work the same way.

Instead of giving random spacing between elements, they follow a **spacing system**.

---

# Example Without a Spacing System

Imagine designing a login screen.

```
Logo

11px

Title

17px

Email

13px

Password

19px

Login Button
```

Every space is different.

The layout feels inconsistent and difficult to maintain.

# Example With a Spacing System

```
Logo

Title

16px

Email

16px

Password

16px

Login Button
```

Everything feels balanced and organized.

This is why designers use spacing systems.

# What is the 4pt System?

The **4pt System** means every spacing value is a **multiple of 4 pixels**.

Examples:

```
4
8
12
16
20
24
28
32
36
40
```

Every value can be divided by **4**.

Examples:

```
16 ÷ 4 = 4

24 ÷ 4 = 6

32 ÷ 4 = 8
```

---

## Simple Definition

> The **4pt System** uses spacing values that are multiples of **4 pixels**.

---

# Example

Imagine a profile card.

```
Profile Picture

8px

Name

4px

Role

16px

Follow Button
```

All spacing follows the 4pt system.

---

# Why Use the 4pt System?

The 4pt system gives designers more flexibility.

It works well for small UI elements such as:

- Icons
- Chips
- Tags
- Badges
- Small buttons

Sometimes 8px feels too large, so designers use 4px instead.

---

# What is the 8pt System?

The **8pt System** means every spacing value is a **multiple of 8 pixels**.

Examples:

```
8
16
24
32
40
48
56
64
```

Every value is divisible by **8**.

---

## Simple Definition

> The **8pt System** uses spacing values that are multiples of **8 pixels**.

---

# Example

Imagine a dashboard.

```
Header

24px

Search Bar

32px

Cards

32px

Footer
```

Every spacing follows the 8pt system.

The layout looks clean and consistent.

---

# Why Do Most Companies Use the 8pt System?

Many design systems use the 8pt system because it provides:

- Consistent layouts
- Easier collaboration between designers and developers
- Faster design decisions
- Better scalability

---

# Real-World Example

Imagine a shopping app.

```
Screen Edge

16px Margin

-----------------------

Product Card

16px Padding

-----------------------

Next Product Card

16px Gap
```

Every spacing value follows the same system.

The interface feels organized and professional.

---

# 4pt System vs 8pt System

| 4pt System | 8pt System |
|------------|------------|
| Multiples of 4 | Multiples of 8 |
| More flexible | More consistent |
| Best for small components | Best for page layouts |
| Used for icons, chips, badges | Used for cards, sections, pages |

---

# Do Designers Use Only One?

No.

Many professional designers combine both systems.

Example:

```
Icon → Text = 4px

Button Padding = 8px

Gap Between Cards = 16px

Gap Between Sections = 32px
```

This keeps the design flexible while maintaining consistency.

# Key Takeaways

- A spacing system keeps UI designs consistent.
- The **4pt System** uses multiples of **4 pixels**.
- The **8pt System** uses multiples of **8 pixels**.
- Avoid using random spacing values.
- Many companies use the **8pt System** for layouts and the **4pt System** for smaller UI components.
- Consistent spacing makes interfaces look cleaner, more professional, and easier to maintain.

---

# Remember

The **4pt System** and **8pt System** are not design styles.

They are **measurement systems** that help designers create consistent layouts, just like using a ruler with standard units instead of guessing measurements.
